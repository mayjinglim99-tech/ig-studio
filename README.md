# Instagram Studio

A small web app that writes Instagram carousels in Isabelle's voice, fact-checks them against her brand profile, and turns them into 1080 × 1350 slides ready to post.

It runs entirely in the browser (hosted free on GitHub Pages):

- **Your OpenAI key** is typed into Settings and stays in that browser on that device. It is never stored in this repository.
- **Your post queue** is saved in the browser too. Use *Back up my posts* / *Restore from backup* to move it between devices.
- **Slide images** are drawn on the device and can be shared straight to Photos or Instagram.

Add it to your phone's home screen (Safari → Share → Add to Home Screen) to use it like an app.
